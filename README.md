# Marketplace

بداية مشروع سوق إلكتروني متعدد البائعين يعمل على Android وiOS باستخدام Flutter.

## التشغيل
1. ثبّت Flutter وAndroid Studio أو VS Code.
2. نفّذ `flutter pub get`.
3. شغّل `flutter run`.

هذه النسخة هي الواجهة الأولى. المرحلة التالية تضيف Backend وقاعدة البيانات والحسابات والإعلانات والصور والمحادثات والإشعارات ولوحة الإدارة.
